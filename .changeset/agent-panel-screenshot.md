**Take a screenshot from the assistant's chat panel.** With `screenshot: true`, the panel gets a Take screenshot button. It captures the page behind the panel with passwords and marked fields blanked, lets the user blur or crop it, and attaches it to the message like any file, so the agent can send it along with a support ticket. The screenshot button can now also hand its image to a file input already on the page instead of uploading it itself.
