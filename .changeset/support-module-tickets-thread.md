The `support` module shows a user their tickets and lets them chat with the team. My tickets in the help panel lists their tickets newest first, the ones the team logged for them included, with the stage, a dot for an unread team reply and the organisation when there is more than one. Opening a ticket shows the thread (images inline, PDFs as file chips, removed messages as "Removed") with a composer for a reply with up to five files. The new `support` page shows the list beside the thread at full width and opens the ticket `?ticket=` names; the `default` menu links to it from the profile menu. Sending a report now opens its thread.
