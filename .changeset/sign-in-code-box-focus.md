**user-account:** After a sign-in email is sent, the cursor is in the code box on the "Check your email" view of the login and signup pages, so the code can be typed or pasted without clicking the box first. This includes a new link sent from the expired-link page. Opening the expired-link page itself leaves the cursor where it was.
